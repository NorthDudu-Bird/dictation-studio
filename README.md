# 词间 · Dictation Studio

导入自己的英语词表，选择词典发音，完成听写、纠错与复习。适配电脑和手机。纯 HTML / CSS / JavaScript，使用时无需 Node.js、前端构建、账号或 API Key。

## 选择版本

| 分支 | 内置内容 |
| --- | --- |
| `main` | 纯净版：12个通用示例词，可自行导入词表 |
| `with-resources` | 资源版：16个主题分类和3个综合听写分组 |

GitHub 页面左上角切换分支，再选择 **Code → Download ZIP**。解压后操作；不要直接在压缩包里打开。也可以克隆仓库后执行 `git switch with-resources` 切换资源版。

## 三分钟开始

1. 安装 Python 3.9 或更新版本，使用当前版本的 Chrome、Edge、Firefox 或 Safari。
2. 在解压出的文件夹打开终端，确认能看到 `server.py`，运行：

   ```sh
   python3 server.py
   ```

   Windows 如果提示找不到 python3，尝试 `py -3 server.py`。
3. 保持终端开启，在同一台电脑的浏览器打开 **http://127.0.0.1:4174/**。
4. 选择词表和练习数量，点击“开始听写”。首次播放被浏览器阻止时，点击一次播放按钮。
5. 输入英文并提交。答错后查看英文和中文，再重新拼写正确，才能进入下一题。

先体验完整流程时，也可以选“看释义，写英文”，这不需要音频网络连接。

端口被占用时执行 `python3 server.py --port 4180`，然后访问终端打印的地址；本地录音代理会自动适配端口。关闭页面前可点“保存并返回”；关闭终端会停止服务。下次运行相同命令，再打开同一地址即可继续。终端按 Ctrl+C 停止服务。

本地服务只监听本机，不是给外网或手机远程访问的生产服务器。手机请使用部署后的 HTTPS 网站。

## 操作和计分

- `Tab`：听写界面重播；`Enter`：提交，答完后下一题。界面按钮也都可点击。
- 单词和短语都有提示；正确答案显示中文释义。
- 每题首次提交计入正确率；当场纠正不重复计分。
- 可选随机、原词表顺序或错误率排序；可勾选“只练待复习错词”。
- 错词复测正确后仍保留历史标记，可在题目下方或学习记录中手动移出；再次答错会重新加入。
- 同一单词跨分类共享统计，常见英美拼写兼容；特殊拼法可用 aliases 指定。
- 离开练习、刷新和关闭页面都会尝试保存草稿；下次点击“继续上次练习”。

## 导入词表

进入“我的词表”，选择 CSV / TSV / TXT / JSON 文件或粘贴文本，填写名称并点击“导入词表”。每次导入添加一份新词表，单份词表内部自动合并重复词。文件最大8MB，一次最多20,000行。

仓库附有可直接导入的 [CSV 示例](examples/words.csv) 和 [JSON 示例](examples/words.json)，页面也可下载 CSV 模板。CSV 推荐保存为 **UTF-8**，BOM 可正常识别。

```csv
term,meaning,category,aliases,audio
accommodation,住宿,旅行,,
colour,颜色,基础,color,
renewable energy,可再生能源,自然,,
```

| 字段 | 说明 |
| --- | --- |
| term | 必填，英语单词或短语；也接受 word / 英文 |
| meaning | 中文或其他语言释义；也接受 zh / translation / 中文 |
| category | 可选分类标签，也接受“分类” |
| aliases | 其他可接受答案，用 \| 分隔；JSON 可用字符串数组 |
| audio | 可选，自有或经授权的 HTTPS 直链音频 |

CSV / TSV 可带表头；无表头时按上述字段顺序读取。带逗号的释义请用双引号包住。TXT 每行一个词；如果希望音频失败时仍能练习，请优先导入带释义的 CSV 或 JSON。

```json
{
  "words": [
    {"term": "colour", "meaning": "颜色", "aliases": ["color"]},
    {"term": "renewable energy", "meaning": "可再生能源", "category": "自然"}
  ]
}
```

## 音源设置

“音源与设置”支持有道、Google Dictionary、自定义模板，以及仅用词表自带音频。优先播放词条自带音频；词典发音先尝试所选口音，再尝试另一口音；勾选回退时也会尝试另一个词典。可选预加载下一词和裁掉首尾空白。

自定义模板例：`https://your-domain.example/audio/{word}/{accent}.mp3`。必须使用 HTTPS，包含 `{word}`（自动 URL 编码）；`{accent}` 为 uk / us。

词典不保证每个词都有录音，也不保证所有地区可访问。**短语不会自动拆词拼接**，请提供短语录音，或使用释义练习。加载失败是“本次不可用”，不等于确定没有真人录音；按 Tab 可重试。应用不会自动切换成机器合成语音，也不将词典音频再分发到仓库。

在本地服务中同时开启“回退”和“去首尾空白”时，会并行准备两个词典的所选口音录音，优先播放先成功的来源，以避免单个词典超时拖慢练习。

## 保存、备份与隐私

- 词表、音源设置、统计和草稿保存在当前浏览器 localStorage；不上传到本项目服务器。
- 浏览器、设备或网站地址不同，记录可能不同。尤其 `localhost`、`127.0.0.1`、不同端口和 `file://` 是不同存储位置，建议固定使用一个地址。
- 清理网站数据、隐私模式关闭、浏览器存储不足都可能导致记录丢失。点击侧栏“导出学习备份”保存 JSON，在“我的词表”恢复备份。
- 恢复会替换当前词表、统计、设置和有效草稿，请先导出当前备份。恢复代码会校验文件内容。
- 纯净版与资源版使用独立存储键，初始记录均为空。资源分类升级保留自行导入的词表与学习记录。
- 播放时词语会发送给所选音源服务。音频最多保留4条内存缓存；浏览器可能产生临时网络缓存，不使用离线音频存储或 Service Worker。
- **不要向 GitHub 提交个人备份、成绩或草稿。** .gitignore 已排除备份、截图、个人数据和凭据文件。

## 静态部署 / GitHub Pages

将本分支根目录的 `index.html`、`app.js`、`styles.css`、`runtime-config.js`、`bundled-data.js` 一起部署，保留文件相对位置。GitHub Pages 可在仓库 Settings → Pages 中选择本分支根目录（具体可用选项以账号为准）。

静态托管支持词表、判分、错词和本地记录，但不能执行 `server.py`，录音会直连音源，受网络、CORS 和音源条款限制。自带音频需由源站允许跨域，才能提前解码去空白；可播放但不支持跨域读取的录音会尝试直接播放。需要更稳定的词典代理时，应部署受控的后端，不能把本地开发服务器直接公开到互联网。

## 常见问题

**为什么没有声音？** 检查系统音量，点击播放；换口音或音源，或关闭“去首尾空白”再试。不能访问 Google 时优先使用有道。仍失败可选释义模式。录音需要网络。

**为什么换浏览器后记录是空的？** 浏览器存储相互独立。导出备份，再在另一浏览器恢复。

**为什么双击 index.html 不推荐？** 文件地址的存储、跨域和音频行为存在浏览器差异。请通过本地服务或 HTTPS 部署使用。

**怎么更新？** 先导出学习备份，再更新应用文件，保留原访问地址。资源包会自动升级内置分类。已有未完成练习使用保存时的题目快照。

## 开发与检查

使用网站不需要 Node.js。维护者可用 Node.js 18+ 执行 `node tests/check.mjs`，用 Python 执行 `python3 tests/smoke.py`。检查不需要第三方依赖；自动检查不依赖外部词典可用性。
