# 词间 · Dictation Studio

可导入词表、切换词典音源的英语听写工具。纯 HTML / CSS / JavaScript，无需前端构建或第三方运行依赖。

## 本地运行

需要 Python 3.9 或更新版本。在本目录执行：

```sh
python3 server.py
```

打开 http://127.0.0.1:4174/ 。这个地址与旧雅思版的 4173 端口独立。

也可通过普通静态服务器托管 `index.html`、`app.js`、`styles.css`、`bundled-data.js`。GitHub Pages 可运行界面及本地记录，录音直接请求音源，受第三方网络与跨域限制；自定义音频需允许跨域才能提前解码去空白。可选 Python 服务只代理两个明确允许的词典音频域名，不保存音频。

## 功能

- CSV、TSV、TXT、JSON 导入；单词、短语、释义、分类、自定义可接受拼写、逐词音频地址。
- 英美常见拼写合并身份；重复词共享统计与释义。
- 听音拼写、看释义拼写；随机、原顺序、错误率排序；错词复习。
- Tab 重播；Enter 提交或下一题；错误须重新拼写正确；首次作答计分。
- 可选去除首尾静音、下一词预加载，最多4条内存缓存。
- 当前浏览器本地记录、未完成进度、备份导出与恢复；无账户和分析追踪。
- 有道、Google Dictionary、自定义 URL 模板与词表自带音频。优先自带录音，词典按口音回退；失败可显示释义。没有静默切换到语音合成。

## 词表格式

CSV / TSV 支持表头 `term,meaning,category,aliases,audio`；也接受 `word`、`zh`、`translation`。CSV 支持带引号的逗号和多行字段。无表头时按上述字段顺序解释。TXT 每行一个词。

```json
{
  "words": [
    {"term": "colour", "meaning": "颜色", "category": "基础", "aliases": ["color"], "audio": ""},
    {"term": "renewable energy", "meaning": "可再生能源", "category": "自然"}
  ]
}
```

自定义音源模板支持 `{word}`（URL编码）和 `{accent}`（uk/us），必须使用 HTTPS 并直接返回音频。第三方词典未承诺稳定开放接口，不保证所有词、地区或短语可用；请遵守音源使用条款。短语不自动拆词拼接，可导入自行授权的录音或使用释义模式。

## 两个版本

- `main`：纯净版，只有12个通用示例词，用户自行导入词表。
- `with-resources`：资源版，包含经整理的分类词表；页面和资源文件不展示作者、机构、出版物或来源信息。

两个版本使用独立的浏览器存储键，初始统计均为空。资源包只含词表，不含任何用户的作答次数、成绩、错词标记、未完成进度，也不含原PDF或录音文件。词表中的地名等学习词条保留。

### 资源版分类

保留三个综合听写分组，其余按主题整合为 P1、P4 及通用基础分类。P1/P4 表示建议的练习用途，不是词条的排他归属，也不表示某道真题的来源。地图词标为 P1/P2，日期、地名与通用表达标为 P1/P4。相同主题不再分成“场景 / 专题 / 高频 / 进阶”多个平行词表；同词确有不同主题用途时允许跨分类保留，统计仍按词共享。每个分类内部合并重复词并保留释义和拼写变体。

升级词表时自动替换内置分类，保留用户自行导入的词表、作答统计和未完成练习快照。资源归类脚本位于 `scripts/regroup-vocabulary.mjs`，接收旧资源包路径并向标准输出输出新包；综合听写分组保持原内容与顺序。

## 数据与开源范围

只发布本仓库内明确跟踪的应用文件。截图、浏览器导出备份、个人记录、原始教材和音频均不随代码发布。原有个人网站单独保留，个人数据不会自动导入本项目。词表资源的使用许可与应用代码的许可范围分开管理，授权依据由维护者在仓库之外留存。

纯净版学习数据保存在浏览器 localStorage 的 `dictation-studio-v1`，资源版使用 `dictation-studio-resources-v1`；不同浏览器不自动同步。导出的备份含个人学习记录，请勿提交到 GitHub。恢复备份会替换当前数据，先导出再恢复。浏览器正常网络栈可能产生临时缓存，本应用不使用 Service Worker 或离线音频缓存。

GitHub 发布前请确定开源许可证；此预览尚未添加许可证，也尚未创建或推送 GitHub 仓库。
